# GÖRÜNÜR Laboratuvarı

İstanbul Öğretmen Akademileri, Sayısal Bilimler Akademisi kapsamındaki **Bilim Sergisi Tasarımı Atölyesi** için öğretmen uygulaması.

GÖRÜNÜR modelinin beş sorusu üzerine kuruludur: **Ne merak ediyoruz? Ne tahmin ediyoruz? Ne gözlemledik? Kanıtımız ne? Nasıl açıklıyoruz?**

## Bölümler

| Hafta | Sekme | İçerik |
|---|---|---|
| 1 · Keşfet | Algı Laboratuvarı | Müller-Lyer çizgileri, Ebbinghaus daireleri, Dikkat Dedektifi; tahmin → gözlem aracı → kanıt → açıklama |
| 1 · Keşfet | Bilim Mahkemesi | İfadeleri tanıklık / kanıt / bulgu olarak sınıflandırma ve jüri kararı (biyoloji ve fizik davaları) |
| 1 · Keşfet | Kayıp Formül | Bilimsel araştırma basamaklarını süreli sıralama |
| 2 · Tasarla | Sergi Stüdyosu | Kazanımdan etkileşimli sergi tasarımı, görünürlük lensi, sergi etiketi önizlemesi |
| 3 · Uygula | Bilim Müzesi | Sergiler, ziyaretçi kartı, fikir değişimi oranı |
| — | Rehber | 3 haftalık akış, 120 dakikalık plan, rubrik, kayıt temizleme |

## Kullanım

- Tek dosyadır (`index.html`); kurulum gerektirmez.
- Çalışmalar yalnızca açıldığı tarayıcıda saklanır; sunucuya veri gönderilmez.
- Online eğitimde: ekranı paylaşın, **Projeksiyon** düğmesiyle yazıları büyütün, katılımcıların sohbetten gelen tahminlerini **+ / −** ile sayın.
- Eğitime başlamadan önce **Rehber → Tüm kayıtları temizle**.

## GitHub Pages ile yayınlama

1. Bu depoya `index.html` ve `README.md` dosyalarını yükleyin.
2. **Settings → Pages → Build and deployment** bölümünde kaynak olarak `main` dalını ve `/ (root)` klasörünü seçin.
3. Birkaç dakika sonra uygulama `https://<kullanıcı-adı>.github.io/<depo-adı>/` adresinde açılır.
